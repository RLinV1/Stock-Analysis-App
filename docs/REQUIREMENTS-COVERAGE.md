# Requirements coverage

Updated 2026-10-15. This is a working inventory, not a claim that the application or a milestone is complete. The approved stack and delivery direction are in [AGENTS.md](../AGENTS.md), [DESIGN.md](../DESIGN.md) and the canonical planned contract, [SPEC.md](SPEC.md). [PRD.md](PRD.md) supplies user stories. The [handoff](../openspec/HANDOFF.md) holds the latest check results; change implementation records hold detailed evidence. A checked source-level test does not prove a live database, LocalStack, Compose, Android device or K3s path.

## Evidence and sequencing

A0 has a tested synthetic runner, fixed holdout, two baselines, recovery and local saved-run comparison. The service has Java unit/MockMvc and Python worker/research checks; current counts are in the [handoff](../openspec/HANDOFF.md). The connected client passed 91 Jest checks, TypeScript/lint, Android/web exports and rendered fixture review. Java 76/76 includes automatic application migration/reopen and repository PostgreSQL cases; worker PostgreSQL 40/40 passes. The real browser/API/PostgreSQL connect/list/submit/status/cancel smoke passes. S3/LocalStack publication, Compose images/startup, completed-result integration, physical phone, v2 replay and historical reproduction remain unverified; see [A0 evidence](A0-EVIDENCE.md).

[DESIGN.md](../DESIGN.md) and [READINESS.md](READINESS.md) place the shared v2/retrievable-input replay contract before B. The bounded v1 synthetic request and a thin B service were implemented first to obtain a usable slice. That is a **sequencing deviation**, not a reduction of A1/B scope and not evidence that A0 artifacts satisfy v2. Keep v1 labels on the synthetic flow; implement the v2 schema, input retrieval and verifier before accepting external manifests or claiming verification. Continue the thin slice while its unsupported replay claims remain explicitly excluded.

The tables separate: **approved scope** (required for the named milestone), **engineering default** (specified starting choice, not an author fact), **proposed decision** (awaiting user acceptance), and **deferred** (approved later work whose prerequisite or user boundary prevents starting now). “Source checked” refers only to the recorded non-live checks.
